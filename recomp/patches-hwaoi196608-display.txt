# 2D layer canvas (set hwaoi_ui_canvas). The game lays its 2D layer out on a
# 1920x1080 canvas. The layer setup at main+576f80 takes the layer's screen size
# from its config (+0x88 -> output {w,h}, else 1920x1080) and builds screen
# cameras from it: perspective (fov 45 deg, near 0.1, far 20000) standing at
# size.h/2 / tan(22.5 deg) from the canvas (inlined at 5770d0, and main+add610
# mode 0), orthographic in size pixels (add610 mode 1); text anchors are mapped
# with output/size. With size = output the canvas spans 1080/output_h of the

# canvas at every output and text scales with it. add610's own perspective path
